## 0. Experimental question

We test a configuration suggested by the hand-drawn sketch: two triangle readings are built in one workspace generated by two parallel carriers and a common transversal. Let the target metric roles be

```text
b  = AB
b' = A'B'
```

and let

```text
gamma, gamma'
```

be the alternate-interior angular roles generated by the same transversal across the two parallel carriers.

The parallel frame stabilizes

```text
gamma = gamma'
```

while the pair-triangle frame can compare `b` and `b'` through Euclid I.25, provided the two carrier-side equalities required by I.25 are independently licensed.

The central questions are:

1. Can a metric disanalogy `b != b'` propagate through the **PAIR** field by I.25 and collide with the angular zero supplied by the **PARALLEL** field?
2. Does the resulting cross-family pressure constitute a useful instance of **disanalogy momentum**?
3. When the same side-to-angle order pattern is read through Euclid I.18 at the **OBJECT** level, does Merovingio detect a strong structural commonality with I.25?
4. Does this expose a representational tension in the current OBJECT↔PAIR homology without yet changing the architecture?

## 1. Geometric licensing boundary

The run separates two layers rigorously.

### 1.1 Proposition-certified core

For I.25 to fire, the pair of triangles must already have two corresponding carrier sides equal. We therefore freeze as input:

```text
carrier_1(T1) = carrier_1(T2)
carrier_2(T1) = carrier_2(T2)
```

One carrier may be the shared transversal segment when the construction literally shares it; the second equality must come from the construction or an earlier certified result. **Parallelism alone does not supply these metric equalities.**

Given those carriers, I.25 licenses:

```text
b > b'  ->  gamma > gamma'
b < b'  ->  gamma < gamma'    [role-swapped orientation]
```

The parallel host, via I.29, licenses:

```text
gamma = gamma'
```

This core is proposition-certified.

### 1.2 Synoptic I.18 comparison

I.18 licenses inside a *single triangle*:

```text
side_1 > side_2  ->  opposite_angle_1 > opposite_angle_2
```

The physical roles `b` and `b'` belong initially to two triangle realizations. Therefore I.18 **cannot** simply be applied to them as a formal proof step unless a separate licensed construction/internalization realizes those compared metric roles inside one triangle.

For this run, the I.18 route is therefore used only as a **cognitive/synoptic comparison**:

```text
OBJECT: metric break -> angular break     [I.18]
PAIR:   metric break -> angular break     [I.25]
```

No new theorem edge is certified from I.18 in the original two-triangle workspace.

This distinction is intentional and is one of the main outputs of the experiment.

# 13. Experimental result

**Result: positive, with an important boundary.**

The pair-order and parallel disanalogy fields combine cleanly inside one workspace and yield a valid reductio proving the target metric equality, provided the I.25 carrier equalities are independently licensed.

I.18 does not add a second formal proof branch yet, but its injection reveals a strong cross-level commonality with I.25:

```text
I.18 = metric-order -> angular-order inside one triangle
I.25 = metric-order -> angular-order across a triangle pair
```

This creates genuine architectural pressure toward a future generalization of object individuation, while the current run remains disciplined and does not smuggle that generalization into the proof.

Most important discovery:

```text
A disanalogy can acquire momentum by propagating through one family
and colliding with the invariant of another family in the same workspace.
```

That mechanism is directly usable by a future proof constructor.

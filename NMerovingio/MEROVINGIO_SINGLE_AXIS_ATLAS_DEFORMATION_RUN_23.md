## 0. Question

Run22 proposed that the parallelogram is not one rigid concept but a stabilized Gestalt visible through several family charts.

Run23 tests whether that atlas is actually generative.

Start at the mutual closure zero:

~~~text
F_DOUBLE_CLOSURE_FIELD

(C1,C2) = (ZERO,ZERO)
~~~

and break **only one** closure coordinate.

Keep:

~~~text
AB || CD
~~~

but deform:

~~~text
AD || BC
~~~

into a finite oriented closure:

~~~text
AD and BC meet at finite apex X
~~~

The question is not:

> Which parallelogram theorem stops being true?

The question is:

> How does the **same material four-edge workspace** reorganize simultaneously in every family chart?

## 6. What happens in the metric-angular chart?

The single topological break does **not** uniquely determine metric or angular values.

After:

~~~text
(ZERO,ZERO) -> (ZERO,RIGHT)
~~~

the four-edge cell may still admit many metric realizations:

~~~text
legs equal or unequal
adjacent sides equal or unequal
angles symmetric or asymmetric
~~~

So the metric/angular chart does not receive one deterministic new coordinate.

Instead it opens a **fiber of possible realizations** over the new closure state.

This is important.

The atlas is therefore not a classical atlas with invertible coordinate transformations.

It behaves more like a:

~~~text
GESTALT CONSTRAINT ATLAS
~~~

where a state in one chart constrains, but may not uniquely determine, states in another chart.

This is a refinement of Run22's atlas hypothesis.

Candidate meta-description:

~~~text
chart transition
=
partial / relational constraint map

not necessarily
=
function
~~~

No new operator follows from this.

## 8. What happens in the diagonal correspondence chart?

The diagonal AC persists materially.

Before the break, both topological channels were at zero:

~~~text

T0 T0
~~~

where T0 means a topological channel at nonclosure zero.

After breaking only the AD/BC channel:

~~~text
source profile:
T0 T+
~~~

where T+ means an oriented finite-closure / nonzero topological state.

The important result is that the diagonal correspondence Gestalt does **not disappear**.

It deforms.

One coordinate remains centered; the other acquires a directional residue.

So instead of representing:

~~~text
ASA-like zero mask
-> broken / unavailable
~~~

we should represent:

~~~text
G_DIAGONAL_PAIR_CORRESPONDENCE

coordinate 1 = ZERO
coordinate 2 = ORIENTED_RESIDUE
~~~

This changes the ontology of the correspondence field itself.

The field should not contain only the zero-source profiles:

~~~text
TT
TM
MT
MM
~~~

It needs internal state on each source coordinate.

For a topological source:

~~~text

~~~

For a metric source, analogously:

~~~text

~~~

The old ASA/SAS/SSS profiles are therefore only **central slices** through a richer residual correspondence field.

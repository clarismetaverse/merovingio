# Transversal Experiment — T1 Run 01

> Scope: one **continuous transversal** intersects two otherwise arbitrary carrier lines at distinct points. No parallelism is assumed. This run tests what becomes available merely because two local intersection packets share one continuous carrier.

---

# 0. Input state

T1 begins from the T0 capabilities:

```text
CONTINUOUS_LINE
LOCAL_INTERSECTION
STRAIGHT_COMPLETION
VERTICAL_OPPOSITION
TRIANGLE_SIDE_EXTENSION
EXTERIOR_ANGLE_TRIANGLE
CROSS_VERTEX_ANGULAR_ORDER
```

and adds one new material configuration:

```text
        g1
---------P---------
          \
           \
            \ t
             \
---------Q---------
        g2
```

with:

```text
P != Q
P,Q lie on one continuous transversal t
P = intersection(t,g1)
Q = intersection(t,g2)
```

No relation between `g1` and `g2` is assumed.

---

# 1. First result: the transversal creates a cross-intersection role map before it creates any equality

At each intersection there is a local angle packet.

```text
P_PACKET = {p1,p2,p3,p4}
Q_PACKET = {q1,q2,q3,q4}
```

Because the same oriented transversal passes through both packets, the reasoner can align roles by:

```text
- same side of transversal
- same side of crossed carrier
- incoming/outgoing transversal direction
- vertical-opposite role
- straight-complement role
```

This yields a **role correspondence**:

```text
p1 ~role q1
p2 ~role q2
p3 ~role q3
p4 ~role q4
```

Important:

```text
ROLE_CORRESPONDENCE != ANGLE_EQUALITY
```

At T1 the reasoner may compare corresponding roles, but it may not infer that their magnitudes are equal.

This is the first genuinely distributed Gestalt capability:

```text
SAME_CONTINUOUS_TRANSVERSAL
    -> CROSS_INTERSECTION_ROLE_ALIGNMENT
```

Status: `COMPILED COGNITIVE CAPABILITY`.

---

# 2. Local packet compression

T0 already gives, at each intersection:

```text
vertical opposition:
    p1 = p3
    p2 = p4

straight completion:
    p1 + p2 = STRAIGHT
```

and similarly at Q:

```text
q1 = q3
q2 = q4
q1 + q2 = STRAIGHT
```

Therefore each four-angle packet can be represented cognitively by one free angular role plus its straight-complement.

Define:

```text
P_PACKET ~= {alpha_P, beta_P}
Q_PACKET ~= {alpha_Q, beta_Q}
```

with:

```text
STRAIGHT_COMPLETION(alpha_P,beta_P)
STRAIGHT_COMPLETION(alpha_Q,beta_Q)
```

and vertical-opposite duplicates implicit.

This is a first example of:

```text
COMPILE(local intersection)
    -> TWO-ROLE ANGULAR PACKET
```

The packet is not numerically parameterized; `alpha` and `beta` are role classes.

---

# 3. Cross-packet relation: the new distributed disanalogy register

T1 can now ask:

```text
R_alpha = rel(alpha_P, alpha_Q)
```

where:

```text
R_alpha in {LT, EQ, GT, UNKNOWN}
```

This relation is not supplied by the transversal itself.

However, because both packets complete to the same straight whole:

```text
alpha_P + beta_P = STRAIGHT
alpha_Q + beta_Q = STRAIGHT
```

comparison in the `alpha` role constrains comparison in the `beta` role.

Define:

```text
R_beta = rel(beta_P, beta_Q)
```

Then the straight-completion Gestalt supports the qualitative inversion:

```text
R_alpha = GT  -> R_beta = LT
R_alpha = LT  -> R_beta = GT
R_alpha = EQ  -> R_beta = EQ
```

Thus T1 exposes a new transducer:

```text
DISTRIBUTED_SUPPLEMENT_TRANSDUCER

rel(alpha_P,alpha_Q)
        <-> inverse-order
rel(beta_P,beta_Q)
```

Stable field:

```text
(alpha relation, beta relation)

(LT,GT)
(EQ,EQ)
(GT,LT)
```

This is structurally different from the triangle order transducers, whose stable states lie on the same-sign diagonal.

The transversal family therefore introduces an **anti-diagonal order organization** generated by a shared whole.

Status: `PROP-LICENSED/COMPILED`, assuming the ordinary Euclidean part-whole comparison for supplements already available from the local straight-angle machinery.

# 4. Second result: one cross-intersection equality is enough to complete the whole angular packet

Suppose one distributed role equality is later established:

```text
alpha_P = alpha_Q
```

Then, since both complete the same straight whole:

```text
beta_P = beta_Q
```

and vertical opposition duplicates both equalities:

```text
p1 = q1
p3 = q3
p2 = q2
p4 = q4
```

up to the chosen role map.

Hence the eight-angle distributed structure has strong closure:

```text
ONE CROSS-PACKET EQUALITY
    + LOCAL STRAIGHT COMPLETION
    + LOCAL VERTICAL OPPOSITION
    -> FULL DISTRIBUTED ANGULAR PACKET MATCH
```

This is a central T1 discovery.

Candidate compiled capability:

```text
TRANSVERSAL_PACKET_COMPLETION
```

Interpretation:

> the transversal does not itself create cross-intersection equality, but once one equality enters the distributed object, the local Gestalten at both intersections propagate it through the whole packet.

```text
F_DISTRIBUTED_ANGLE_PACKET
```

```text
Z_DISTRIBUTED_PACKET:
    R_alpha = EQ
    R_beta  = EQ
```

```text
    R_alpha = GT
    R_beta  = LT

    R_alpha = LT
    R_beta  = GT
```

The zero state is not yet called `PARALLEL` at T1.

It is only:

```text
ZERO CROSS-PACKET ANGULAR RESIDUE
```

Parallelism remains an OPEN host interpretation to be propositionally certified later.

This preserves the experimental separation:

```text
ANGLE-PACKET ZERO
    != automatically

```

# 6. Localization Gedanken: collapsing packets along the continuous transversal

T1 now has enough structure to use the experimental cognitive operator:

```text
COLLAPSE_ALONG_TRANSVERSAL(P,Q)
```

The operator preserves:

```text
- orientation of t
- side-of-transversal roles
- straight-complement roles
- vertical-opposition roles
- genealogy of each packet
```

while counterfactually co-locating P and Q for comparison.

Possible readout:

```text
alpha_P overlays alpha_Q
```

and a residual angular/directional discrepancy may remain.

Define a cognitive residue:

```text
DELTA_PACKET
```

such that:

```text
DELTA_PACKET = ZERO
    -> distributed packets align under localization

DELTA_PACKET != ZERO
    -> one packet is a rotated/disanalogical variant of the other
```

At T1 this residue is an explanatory device, not a numerical angle and not a proof of parallelism.

---

# 7. Important new distinction: material carrier vs crossed-carrier orientation

The continuous transversal provides a true shared material carrier:

```text
t_P and t_Q belong to one line t
```

The crossed lines `g1` and `g2` do not yet share a direction class.

Therefore:

```text
shared transversal direction = CERTIFIED
shared crossed-carrier direction = OPEN
```

This prevents a crucial shortcut:

```text
same-looking corresponding angle positions
    -/->
g1 parallel g2
```

The reasoner can align *roles* across P and Q before it is allowed to identify *direction classes*.

---

# 8. Counterfactual A — rotate the second crossed carrier

Keep:

```text
t continuous
P packet fixed
Q on t
```

and rotate `g2` around Q.

```text
BREAK_CARRIER_DIRECTION(g2)
```

The immediate effect is a change in one local role at Q:

```text
alpha_Q -> alpha_Q'
```

but local straight completion forces:

```text
beta_Q -> beta_Q'
```

with inverse ordering.

Therefore a one-carrier deformation propagates through the whole Q packet.

Cross-packet result:

```text
R_alpha changes
R_beta changes inversely
```

This yields a clean disanalogy genealogy:

```text
CARRIER-DIRECTION BREAK [SEED]
    -> alpha cross-relation [PROPAGATED]
    -> beta cross-relation  [PROPAGATED, inverse]
    -> full packet disanalogy
```

This is the transversal analogue of the triangle-side/angle propagation family.

---

# 9. Counterfactual B — break transversal continuity

Now preserve the two local intersection geometries but replace the one continuous transversal by two collinear-looking local fragments with a bend/discontinuity between P and Q.

```text
BREAK_TRANSVERSAL_CONTINUITY
```

This destroys the certified cross-intersection role alignment.

The local packets remain valid:

```text
P_PACKET valid
Q_PACKET valid
```

but the distributed object loses its common carrier genealogy.

Hence:

```text
LOCAL GEOMETRY PRESERVED
DISTRIBUTED ROLE MAP LOST
```

Residue:

```text
DIRECTIONAL_RESIDUE(t) != ZERO
```

This is a particularly useful example because the failure is not primarily metric or angular; it is a failure of **one carrier to support two local views**.

Therefore `DIRECTIONAL_RESIDUE` is retained as a distinct residue type.

# 10. T1 effect on Gestalt completion theory

T1 sharpens `COMPLETE`.

At T0, completion was mainly local:

```text
angle + adjacent angle -> straight whole
```

At T1, the same local completion can be coupled across two sites:

```text
P local whole
    +
Q local whole
    +
same transversal carrier
    ->
distributed comparison field
```

A Gestalt can therefore complete not only missing relations, but also a **shared comparison frame**.

New candidate completion label:

```text
FRAME_COMPLETION
```

Meaning:

> a common carrier does not determine equality, but supplies a stable role frame in which distributed relations become comparable.

Do not yet hard-code `FRAME_COMPLETION` as a primitive; log it as an empirical phenomenon.

# 14. New family-level homology

The triangle network contained:

```text
OBJECT_ORDER_TRANSDUCER
    stable same-sign states:
    (LT,LT), (EQ,EQ), (GT,GT)
```

T1 now adds:

```text
DISTRIBUTED_SUPPLEMENT_TRANSDUCER
    stable inverse-sign states:
    (LT,GT), (EQ,EQ), (GT,LT)
```

Therefore the network now contains two qualitatively different relation-preservation grammars:

```text
ORDER-PRESERVING TRANSDUCER
    X order -> same Y order

WHOLE-COMPLEMENT TRANSDUCER
    X order -> inverse Y order
```

This is a significant family-level enrichment.

The shared zero `(EQ,EQ)` is structurally notable: equality is a fixed point of both the preserving and reversing transducers.

Candidate future question:

```text
Do higher-symmetry Gestalten arise where several different transducers share the same zero state?
```

This may later connect naturally to square/parallelogram experiments.

# 16. Main T1 conclusion

The most important result is not an equality theorem.

It is:

```text
ONE CONTINUOUS TRANSVERSAL
    -> ONE DISTRIBUTED ROLE FRAME
```

The shared carrier makes two previously independent local intersection Gestalten members of one comparison object.

Within that object:

```text
one cross-role relation
    -> via local vertical/straight completion
    -> a whole packet of constrained cross-relations
```

Thus the transversal already creates **inferential matter** before parallelism appears.

Its first contribution is not to say which remote angles are equal.

Its first contribution is to make remote angles **systematically comparable and mutually constraining**.

This is the T1 control result to preserve before introducing I.27/I.28-style parallel certification.

# Triangle Multi-Agent Square-Diagonal Reinjection — Run 07

> Controlled dry run under `MEROVINGIO_COGNITIVE_ARCHITECTURE_V03.md`.
>
> Input: the composite-zero parallelogram family discovered in Run 06, plus the triangle/correspondence/parallel machinery discovered in Runs 01–05.
>
> Goal: cut the composite-zero four-edge configuration by a diagonal and reinject the resulting sub-configurations into the earlier triangle network, then observe whether the agents recover a richer triangle organization without preloading the labels `SQUARE`, `RIGHT ISOSCELES TRIANGLE`, `DIAGONAL SYMMETRY`, or `ZERO PROJECTION`.
>
> This is a conceptual dry run, not an autonomous software execution.

---

# 0. Hidden-target discipline

The agents are **not** told to discover:

```text

RIGHT_ISOSCELES_TRIANGLE
SQUARE_DIAGONAL_SPLITS_INTO_TWO_RIGHT_ISOSCELES_TRIANGLES

```

They may use only the already compiled network plus the new material operation:

```text

```

Success is structural, not terminological.

A strong run should detect at least some of the following without being told them:

```text
1. one diagonal creates two triangle workspaces sharing one carrier;
2. both triangles instantiate the previously discovered triangle equality-zero;
3. the pair of triangles also instantiates a pair-congruence zero;
4. the host composite-zero contributes an additional angular zero not intrinsic to the old triangle family;
5. the same diagonal participates simultaneously in OBJECT-, PAIR-, and HOST-level readings;
6. the older triangle zero is therefore a partialization of a richer composite-zero host;
7. the network should gain a rule for projecting zero-structure from a host into sub-Gestalten and possibly recomposing it back.
```

# 6. Angular-zero inheritance from the host

The Reorganization Agent now inspects `A = EQ` in the host.

Within a parallelogram family, adjacent host angles are supplementary.

Thus:

```text
adjacent host angle 1 + adjacent host angle 2 = STRAIGHT
```

while the composite-zero condition gives:

```text
adjacent host angle 1 = adjacent host angle 2
```

Therefore the two equal angular roles are each half of one straight whole.

The network may compile the readout:

```text
HOST_ANGLE_ZERO
    = equal adjacent supplementary angles
    = RIGHT_ANGLE_ROLE
```

Human semantic naming may later call this a right angle; the agent stores the structural condition first.

Now each diagonal triangle inherits one such host corner:

```text
T1 contains one HOST_ANGLE_ZERO corner
T2 contains one HOST_ANGLE_ZERO corner
```

So each triangle now carries two independent zero conditions:

```text
internal metric/side zero
+
host-derived angular fixed-point zero
```

This generates a new impetus.

# 17. Main result

The reinjection does more than recover a known diagonal property.

It reveals that **zero-structure itself is transportable across organizational levels**.

A rich host can be decomposed so that:

```text
HOST COMPOSITE ZERO
      |
      | PARTIALIZE / DIAGONALIZE
      v
OBJECT ZERO + OBJECT ZERO
      |
      | shared carrier / pair view
      v
PAIR ZERO
```

and one of the host's independent zero conditions may survive as an **inherited local zero** inside each sub-Gestalt.

This means the network should no longer ask only:

```text
"What is the zero of this family?"
```

but also:

```text
"From which richer hosts can this zero be projected?"
"Which additional zero conditions can it inherit?"
"Can a compatible collection of local zeros be recomposed into a richer host?"
```

That is the key conceptual gain of Run 07.

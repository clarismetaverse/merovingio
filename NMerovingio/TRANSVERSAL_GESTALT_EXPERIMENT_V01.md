# Transversal Gestalt Experiment v0.1

> Independent experimental specification to be injected later into `TRIANGLE_GESTALT_NETWORK_V02.md`.
>
> The purpose is **not** to assume parallelism in advance. The purpose is to build the cognitive machinery of straight lines, intersections, external triangle angles, and a distributed transversal, then observe which new Gestalten and backward enrichments appear when this network is injected into the triangle network.

---

# 0. Experimental question

Can a transversal/intersection network reorganize already-known triangle Gestalten by making angular relations **distributed, transportable, localizable, and completable**?

The main hypothesis to test is:

```text
local triangle relation
    -> HOST in transversal/intersection workspace
    -> distributed angular completion
    -> PROJECT back to triangle
    -> BACKWARD_ENRICH old triangle Gestalt
    -> EVOKE a transversal/parallel construction in future reasoning
```

The experiment must distinguish:

```text
1. proof-valid geometric facts;
2. cognitive host hypotheses;
3. counterfactual constructions;
4. newly compiled Gestalten.
```

No parallel fact may be silently assumed merely because a diagram looks parallel.

---

# 1. Terminology: straight-angle completion

When two adjacent angles fill one straight angle, the technically correct relation is **supplementarity**, not 90-degree complementarity.

In this project we will use:

```text
STRAIGHT_COMPLETION(alpha, beta)
```

for:

```text
alpha + beta = STRAIGHT_ANGLE
```

This is useful because the cognitive operation is not merely numeric addition. It is the completion of two angular parts into one continuous linear whole.

# 3. Level 1A — local intersection Gestalt

Let two continuous lines `l` and `t` intersect at `O`.

Represent four oriented rays:

```text
l_minus, l_plus
t_minus, t_plus
```

and four angular sectors:

```text
q1 = angle(l_plus,  t_plus)
q2 = angle(t_plus,  l_minus)
q3 = angle(l_minus, t_minus)
q4 = angle(t_minus, l_plus)
```

## 3.1 Local role structure

The intersection Gestalt exposes two simultaneous organizations:

```text
OPPOSITION
    q1 <-> q3
    q2 <-> q4

ADJACENT STRAIGHT COMPLETION
    q1 + q2 -> straight angle on l
    q2 + q3 -> straight angle on t
    q3 + q4 -> straight angle on l
    q4 + q1 -> straight angle on t
```

The important point is that a straight line acts as a **completion carrier**.

Two adjacent angular pieces become inferentially co-present because they are recognized as parts of one continuous line.

## 3.2 Candidate local Gestalten

```text
G_STRAIGHT_COMPLETION
    two adjacent angular parts
    + shared vertex
    + opposite rays as one continuous carrier
    -> one straight-angle whole

G_VERTICAL_OPPOSITION
    two opposite angular sectors
    + two intersecting continuous lines
    -> candidate equal-angle relation
```

`G_VERTICAL_OPPOSITION` may be proposition-certified by Euclid I.15; do not treat equality as primitive if the experiment is run proposition-by-proposition.

The last capability is especially important because earlier triangle-only experiments exposed a missing cross-vertex angular-order bridge.

# 5. Level 1B — external-angle triangle Gestalt

Let triangle `ABC` have side `BC` extended through `C` to `D`.

```text
B ----- C ----- D
         \
          \
           A
```

Define:

```text
interior_at_C = angle(BCA)
exterior_at_C = angle(ACD)
```

Because `BC` and `CD` are opposite rays on one continuous line:

```text
STRAIGHT_COMPLETION(
    interior_at_C,
    exterior_at_C
)
```

This creates the first explicit bridge between triangle reasoning and transversal/intersection reasoning.

## 5.1 Two simultaneous memberships

The exterior angle belongs to at least two candidate Gestalten:

```text
TRIANGLE_VIEW
    exterior angle as an extension-generated triangle relation

LINEAR_VIEW
    exterior angle as one part of a straight-angle completion
```

Hence the same angle can be a **multi-Gestalt hinge**.

## 5.2 Rebase affordance

The reasoner may REBASE from:

```text
triangle as ground
```

to:

```text
extended side / straight line as ground
```

without changing the material configuration.

This is a concrete test of vertical rebase and active-family switching.

# 6. Level 2 — distributed transversal Gestalt

Let one continuous transversal `t` intersect two carrier lines `g1` and `g2` at distinct points `P` and `Q`.

```text
       g1
---------P---------
          \
           \
            \  t
             \
---------Q---------
       g2
```

No relation between `g1` and `g2` is assumed initially.

The pair object is:

```text
DistributedTransversalPair {
    transversal: t
    intersection_1: P
    intersection_2: Q
    carrier_1: g1
    carrier_2: g2
}
```

## 6.1 Local packets

Each intersection has its own local angle packet:

```text
P_packet = {p1,p2,p3,p4}
Q_packet = {q1,q2,q3,q4}
```

The continuous transversal provides a shared orientation and a shared carrier genealogy across both packets.

This is the crucial new epistemic contact:

```text
same continuous transversal
    -> two separated intersection Gestalten can be compared as one distributed object
```

# 7. Continuous-line counterfactual: localize the distributed transversal

A central Gedanken operation is to treat the two intersections **as if their angular packets were brought together along the same continuous transversal**.

Define:

```text
COLLAPSE_ALONG_TRANSVERSAL(P, Q)
```

This does **not** assert that `P = Q` geometrically.

It is a cognitive/counterfactual localization operator:

```text
preserve:
    orientation of t
    side-of-t roles
    angle-role genealogy

counterfactually identify:
    the two intersection centers for comparison
```

The output is a candidate localized angular configuration.

Purpose:

```text
remote angular pieces
    -> counterfactual co-location
    -> test whether they complete into a local straight-angle Gestalt
```

The inverse operator is:

```text
DISTRIBUTE_ALONG_TRANSVERSAL
```

which takes a local angular relation and separates its components over two intersections while preserving the shared transversal carrier.

This pair is a central experiment:

```text
LOCALIZE <-> DISTRIBUTE
```

# 8. Distributed straight-angle Gestalt

A local straight angle has:

```text
alpha + beta = STRAIGHT
```

The distributed hypothesis asks whether two remote angular roles, one at `P` and one at `Q`, can behave as the two parts of one straight-angle whole after `COLLAPSE_ALONG_TRANSVERSAL`.

Represent:

```text
DistributedStraightCompletionCandidate {
    angle_at_P
    angle_at_Q
    transversal_roles
    side_roles
    localization_map
    residual_angle
    status
}
```

Possible outcomes:

```text
residual_angle = ZERO
    -> distributed completion succeeds

residual_angle != ZERO
    -> angular disanalogy remains

status = UNDECIDED
    -> more structure/theorem support required
```

This is the formal version of the intuition that parallelism may encode a **distributed straight angle**.

It is a hypothesis to test, not a primitive theorem.

# 9. Dis-transversal counterfactual family

The transversal itself must have analogical and disanalogical variants.

## 9.1 Canonical continuity zero

```text
TRANSVERSAL_CONTINUITY_ZERO
    t is one continuous straight carrier through P and Q
    direction_residue(t) = ZERO
```

## 9.2 Break A — bent transversal

Break continuity between the local intersection packets:

```text
BREAK_TRANSVERSAL_CONTINUITY
```

Produce:

```text
direction_residue != ZERO
```

Interpretation:

```text
what had been one direction-class splits into two local direction roles
```

This is a **directional disanalogy seed**.

## 9.3 Break B — rotate one crossed carrier

Keep `t` continuous but vary `g2` while preserving `g1`.

```text
BREAK_CARRIER_DIRECTION(g2)
```

This changes selected cross-intersection angle relations while preserving the transversal.

Output:

```text
angular_residue != ZERO
```

This gives a clean family for studying how a local directional break propagates into remote angular correspondence.

## 9.4 Break C — break a distributed angular equality

Start from a later stabilized distributed equality and perturb only one matched angular role:

```text
BREAK_DISTRIBUTED_ANGLE_EQUALITY
```

Track whether the break:

```text
- remains local;
- propagates to a second angle class;
- forces a carrier-direction change;
- produces a straight-completion residue;
- destabilizes a candidate parallel Gestalt.
```

## 9.5 Break D — break straight completion

Start from:

```text
alpha + beta -> STRAIGHT
```

and introduce an angular residue:

```text
alpha + beta + gamma -> STRAIGHT
```

or equivalently:

```text
alpha + beta = STRAIGHT - gamma
```

Record:

```text
gamma = ANGULAR_RESIDUE
```

Then allow `REBASE(gamma)` as a future generative move.

Only after a parallel Gestalt has been licensed may an I.29-like pattern add:

```text

    -> complete more ANGLE PATTERNS
    -> project back
    -> enriched ANGLE PATTERN
```

This is allowed in the cognitive graph while proof certificates remain acyclic.

# 14. Triangle-host hypotheses to test after injection

The following are **experimental hypotheses**, not preloaded facts.

## H1 — ASA as embeddable in a distributed transversal/parallel host

Given:

```text
angle_1(T1) = angle_1(T2)
carrier_side(T1) = carrier_side(T2)
angle_2(T1) = angle_2(T2)
```

ask whether the angle equalities can be re-read as two distributed direction classes once a suitable transversal/parallel host is constructed.

If validated:

```text
ASA_PAIR
 -> HOST(distributed directional Gestalt)
 -> COMPLETE
 -> PROJECT
 -> BACKWARD_ENRICH(ASA)
```

Possible learned affordance:

```text
EVOKE_PARALLEL_OR_TRANSVERSAL_HOST
```

## H2 — exterior triangle angle as bridge to straight-completion Gestalt

Given a triangle vertex with one side extended:

```text
TRIANGLE_ANGLE
 + EXTERIOR_ANGLE
 -> STRAIGHT_COMPLETION
```

Test whether this creates new host paths between triangle order reasoning and intersection/transversal reasoning.

## H3 — cross-vertex angular order

Test whether I.16-like exterior-angle capability supplies the bridge that earlier triangle-only disanalogy runs lacked.

Specifically:

```text
triangle disanalogy frontier
    -> extend a side
    -> host in straight/exterior-angle Gestalt
    -> compare cross-vertex angular roles
    -> project order relation back
```

This must be tested without leaking I.18/I.19 as targets.

## H4 — local triangle angles as projections of a distributed straight-angle whole

Leave this initially open.

Later, after enough parallel structure is licensed, test whether triangle angles can be transported/localized into a single straight-angle Gestalt.

This hypothesis points toward I.32 but must not be used in earlier phases.

# 18. Experiment phases

## Phase T0 — local line/intersection network

Load only:

```text
continuous line
intersection
straight-angle completion
triangle side extension
I.13-like straight completion
I.15-like vertical opposition
I.16-like exterior-angle order
```

Measure how much of the triangle network is enriched **without** any two-intersection transversal.

## Phase T1 — distributed transversal without parallelism

Add:

```text
one continuous transversal
P/Q intersection packets
LOCALIZE_ALONG_TRANSVERSAL
DISTRIBUTE_ALONG_TRANSVERSAL
counterfactual continuity breaks
carrier rotations
```

Do not add I.27-I.29 yet.

Measure which triangle patterns become embeddable, even if no parallel host is certified.

## Phase T2 — parallel-producing criteria

Add I.27/I.28-like proposition roles.

Test whether equality/supplementarity patterns now compile a new `PARALLEL_GESTALT`.

Record exactly which prior angle patterns become newly interpretable as **causes/entry conditions** for that host.

## Phase T3 — parallel consequences

Add I.29-like proposition roles.

Now allow the parallel host to complete additional angle correspondences.

This phase tests true circular Gestalt reasoning:

```text
angle pattern
 -> parallel host
 -> more angle relations
 -> enriched old angle pattern
 -> future evocation of parallel host
```

## Phase T4 — inject into TriangleNet v0.2

Let:

```text
N_triangle = TRIANGLE_GESTALT_NETWORK_V02
T3         = stabilized transversal network after Phase T3
N_after    = INJECT(N_triangle, T3)
```

Then compute qualitative:

```text
DeltaN = N_after - N_triangle
```

# 21. Core expected discoveries, not assumptions

The experiment is designed to test whether the following emerge:

```text
A. straightness acts as a completion carrier;
B. a transversal is a device for distributing one local angular grammar over two vertices;
C. parallelism behaves like a zero-residue distributed angular Gestalt;
D. exterior triangle angles are hinges between triangle and line/intersection families;
E. ASA can be reinterpreted through a distributed direction/parallel host;
F. later transversal Gestalten retroactively enrich old triangle Gestalten;
G. local and distributed straight-angle completion are two views of one family;
H. dis-transversal counterfactuals reproduce the analog/disanalog logic already seen in triangles.
```

None of A-H should be considered validated merely because it appears plausible in a diagram.

# 22. Research thesis for this experiment

The transversal is treated not merely as a line crossing other lines, but as a **carrier that can separate, transport, compare, and re-localize angular roles**.

The strongest working hypothesis is:

```text
A continuous line can make angular relations at different places behave as parts of one inferential whole.
```

If that hypothesis is validated proposition-by-proposition, the transversal network should provide the first clear example of a Gestalt that:

```text
1. receives old triangle relations as local projections;
2. completes them in a larger distributed workspace;
3. returns new readouts to the triangle network;
4. teaches the triangle network how to evoke the larger construction in future reasoning.
```

That is the intended test of circular Gestalt reasoning.

## 0. Conceptual pressure

Runs 18–21 produced useful structure, but their language drifted toward:

~~~text
new relation
-> new named mechanism
-> new capability/operator candidate
~~~

Run22 rewrites the same material in the opposite direction:

> What changes in the **families of Gestalten and their ontology** if we stop treating every new path as a new mechanism?

The target is not a proof. The target is to understand what the same parallelogram/diagonal workspace **becomes** when read through several existing families.

## 1. One material support, several family readings

Keep one rich workspace W* with boundary A-B-C-D-A and diagonal AC.

The same material support is already appearing in at least four families:

~~~text
F1  transversal / closure family
F2  double-parallel / parallelogram family
F3  metric-angular parallelogram product family
F4  triangle-pair correspondence / congruence family
~~~

The first ontological correction is:

~~~text
PARALLELOGRAM
!=
one concept with one defining family
~~~

Prefer:

~~~text
G_PARALLELOGRAM*
=
one stabilized Gestalt with several family realizations
~~~

## 2. Runs 18A/18B reveal a two-dimensional closure field

Run18A varied one pair of transversals while keeping the other direction class fixed.

Each transversal pair has a qualitative closure coordinate:

~~~text
C in {LEFT_CLOSURE, NONCLOSURE_ZERO, RIGHT_CLOSURE}
~~~

Run18B then showed that the same four-edge workspace contains **two such closure readings simultaneously**.

So the richer family is not merely one closure axis but a product-like field:

~~~text
F_DOUBLE_CLOSURE_FIELD

C1 = closure state of opposite pair / transversal system 1
C2 = closure state of opposite pair / transversal system 2
~~~

The double-parallel cell sits at:

~~~text
(C1,C2) = (ZERO,ZERO)
~~~

Thus the parallelogram is more strongly:

~~~text
PARALLELOGRAM
=
MUTUAL / DOUBLE ZERO
of a two-axis closure field
~~~

A break of only one zero moves along one axis and produces a triangle-generating deformation while preserving the other axis.

So the triangle configurations are not external examples attached to the parallelogram. They are **nearby deformations in the same family field**.

This is the first major ontology improvement.

## 3. The metric-angular parallelogram family is another chart, not a competitor

Earlier Merovingio already had F_PARALLELOGRAM_PRODUCT with metric and angular registers.

Run18 showed that the same material Gestalt is central / double-zero in F_DOUBLE_CLOSURE_FIELD while it may be generic in F_PARALLELOGRAM_PRODUCT unless metric/angular equalities are added.

This should not be represented as two different parallelogram concepts.

It is better represented as two **charts on the same Gestalt**:

~~~text
TOPOLOGICAL CHART
  coordinates = closure / nonclosure

METRIC-ANGULAR CHART
  coordinates = side relation / angle relation
~~~

Hence:

~~~text
ZERO_STATUS_IS_CHART_RELATIVE
~~~

is more precise than inventing a new zero operator.

## 4. Runs 19–21 reveal a diagonal correspondence chart

Insert diagonal AC.

The parent workspace can now be partialized into triangle ABC and triangle CDA, but the important discovery is not the partition itself.

The important discovery is that each opposite-side channel can be **read in two domains**:

~~~text
T = topological / directional reading
    e.g. opposite carriers at nonclosure zero

M = metric reading
    e.g. corresponding opposite side equality
~~~

and the diagonal provides a fixed shared identity bridge:

~~~text
I = AC / CA
~~~

So the richer family is:

~~~text
F_DIAGONAL_CORRESPONDENCE_FIELD

channel 1 source in {T,M}
channel 2 source in {T,M}
shared bridge = I
~~~

The four source profiles are:

~~~text
TT
TM
MT
MM
~~~

Runs19–21 gave familiar surface labels:

~~~text
TT -> ASA-like
TM -> SAS-like
MT -> SAS-like mirrored
MM -> SSS-like
~~~

The ontology rewrite is:

~~~text
ASA / SAS / SSS
are not primary isolated objects here.

They are named surface profiles
inside one deeper diagonal correspondence field.
~~~

This is the second major ontology improvement.

## 5. Collapse the apparent proliferation of Gestalten

Runs19–20 provisionally suggested separate objects such as G_ASA_PARALLELOGRAM_DIAGONAL_HOST and G_SAS_PARALLELOGRAM_DIAGONAL_HOST.

Run22 reinterprets them as unnecessary duplication.

Prefer one richer Gestalt:

~~~text
G_DIAGONAL_PAIR_CORRESPONDENCE
~~~

with:

~~~text
source_profile = TT | TM | MT | MM
~~~

and a correspondence reading such as coherent / partial / unstable.

The human theorem labels are attached only as familiar aliases to regions of this field.

Thus:

~~~text
same correspondence Gestalt
+ different genealogical source profile
!=
different Gestalt
~~~

unless later deformation shows a genuine ontological split.

## 7. The deeper picture: an atlas of families around one Gestalt

Runs18–21 together suggest not merely multi-membership, but something atlas-like.

~~~text
                     [ G_PARALLELOGRAM* ]
                      /        |        \
                     /         |         \
          closure chart   metric/angular   diagonal
             C1 x C2          chart        correspondence chart
                                           {TT,TM,MT,MM}
~~~

These are not competing definitions. They are different coordinate systems / partializations over the same constructive support.

Candidate meta-structure:

~~~text
GESTALT_FAMILY_ATLAS
~~~

This is **not an operator**.

It represents that one Gestalt can have several locally natural family descriptions, with transition genealogies between them.

The transitions use already-known cognitive moves such as partialization, project, reindividuation, rebase, recomposition, and decompile.

## 8. Analogy changes meaning

The stronger analogical event is not merely object A resembles object B.

It is:

~~~text
two previously distinct descriptions
turn out to be coordinate charts
of the same underlying Gestalt/family field
~~~

Example: ASA / SAS / SSS were initially separate congruence criteria. After the parallelogram injection, TT / TM / MT / MM appear as neighboring regions of one deeper correspondence field.

That is an ontology change produced by analogy.

## 9. Disanalogy changes meaning

A break is not primarily “a failed theorem condition.”

A break moves the Gestalt through its family field.

Examples:

~~~text
break one closure zero
  -> move away from (0,0)
  -> one triangular apex family emerges

change one channel source T -> M
  -> move TT -> TM
  -> the same diagonal correspondence is read through a mixed genealogy
~~~

So a disanalogy can be represented as a **direction of motion in family space**.

This is stronger than naming a new relation for each break.

## 10. What changed ontologically?

Before Runs18–21, parallel, parallelogram, ASA, SAS, SSS, and triangle-pair congruence were comparatively separated concept types.

After reinterpretation:

### A. Parallel / parallelogram / triangle closure

They become regions of:

~~~text
F_DOUBLE_CLOSURE_FIELD
~~~

with the parallelogram as mutual zero and triangle-producing forms as deformations.

### B. ASA / SAS / SSS

They become source profiles of:

~~~text
F_DIAGONAL_CORRESPONDENCE_FIELD
~~~

rather than primary isolated masks.

### C. The parallelogram itself

It becomes a **cross-family stabilization**:

~~~text
in closure field:
  mutual zero

in metric/angular field:
  a state with free/evolving registers

in diagonal correspondence field:
  a rich host supporting several source profiles

in triangle deformation field:
  central state from which triangular closures emerge
~~~

The concept is identified less by one definition and more by the **stable intersection of several family readings and genealogies**.
